# Repository guidance

- This is a public repository. Remove private data, client details, and personal examples before committing.
- Use Conventional Commits with short, specific subjects.
- Keep the README concise and update its skill list whenever the catalog changes.
- Keep every skill focused on one clear job and compatible with the Agent Skills specification.
- Run the skill validator and the local `npx skills@latest add . --list` check before committing.
- Use the `say-it-normally` skill for public copy in this repository.
