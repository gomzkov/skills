# Repository guidance

- This is a public repository. Remove private data, client details, and personal examples before committing.
- Keep every skill focused on one clear job and compatible with the Agent Skills specification. Add supporting files only when needed.
- Keep the README short and update its skill table whenever the catalog changes.
- Run the skill validator and the local `npx skills@latest add . --list` check before committing.
- Use Conventional Commits and apply `say-it-normally` to public copy.
